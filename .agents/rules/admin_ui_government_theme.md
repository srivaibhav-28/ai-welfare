# Permanent Rules: Admin UI Government Theme & Project Scope Restrictions

## 🚨 PERMANENT RULES (APPLY FOR EVERY FUTURE CHANGE)

## 🇮🇳 ADMIN DESIGN SYSTEM (OFFICIAL INDIAN GOVERNMENT PORTAL)

### Palette Tokens
- **Primary Saffron**: `#FF9933` (Hover: `#E68A00`)
- **India Green**: `#138808`
- **Blue Accent**: `#0B5ED7`
- **Danger Red**: `#DC3545` / `#DC2626`
- **Background**: `#F8F9FA`
- **Card Surface**: `#FFFFFF`
- **Header Surface**: `#FFFFFF`
- **Sidebar Surface**: `#FFFFFF`
- **Border**: `#E5E7EB`
- **Primary Text**: `#1F2937`
- **Muted Text**: `#6B7280`

### Element Styling Guidelines
- **Header**: Pure White (`#FFFFFF`), Saffron Admin Badge, thin Saffron bottom border (`3px solid #FF9933`).
- **Sidebar**: Pure White (`#FFFFFF`), Saffron active menu item (`#FF9933`) with white text, grey border (`#E5E7EB`), soft hover (`#FFF3E0`).
- **Cards**: Pure White (`#FFFFFF`), 16px radius, soft shadow (`0 4px 12px rgba(0,0,0,0.08)`), thin border (`#E5E7EB`), top accent border mapped per card type (Users: Orange, Schemes: Green, Apps: Blue, Pending: Orange, Approved: Green, Rejected: Red).
- **Tables**: Pure White (`#FFFFFF`), Blue table header (`#0B5ED7`), white header text, Saffron bottom border (`3px solid #FF9933`), light row hover (`#FFF3E0`).
- **Buttons**: Primary Orange (`#FF9933`), Secondary White (`#FFFFFF` with orange border), Success Green (`#138808`), Danger Red (`#DC3545`).
- **Badges**: Citizen (Blue `#0284C7`), Admin (Navy `#0B3D91`), Pending (Orange `#D97706`), Approved (Green `#138808`), Rejected (Red `#DC2626`).
- **Typography**: Inter / Poppins with clean spacing and bold headings.
